# HIIT Timer v0.1

HTML / CSS / Vanilla JavaScriptで動く、スマートフォン向けのHIITタイマーです。外部ライブラリ、ビルド、バックエンドは不要です。

## 使い方

1. `index.html`をブラウザで開きます。
2. 種目名・種目数・周回数と、準備運動・共通の運動時間・共通の休憩時間・整理運動の秒数を設定します。
3. STARTで開始します。現在の種目、残り時間、NEXT、周回・種目番号を表示します。
4. Pause / Resume、停止中のStop、Previous / Nextで操作できます。Stopは設定を維持して設定画面に戻ります。

準備運動・整理運動は0秒で省略できます。運動・休憩は1秒以上です。各運動の後には、最終種目を含めて休憩が入ります。

初期設定は6種目×1周、準備120秒・運動20秒・休憩40秒・整理60秒で、14区間・合計9分です。設定の永続保存はありません。

## ローカルサーバーで実行する

Node.jsを利用できる環境で、プロジェクトフォルダから実行します。npmパッケージのインストールは不要です。

```sh
node dev-server.cjs
```

PCでは `http://localhost:8000` を開きます。同じWi-FiのiPhoneでは、Safariで `http://<PCのIPv4アドレス>:8000` を開いてください。Windowsでは `ipconfig` で使用中のWi-FiのIPv4アドレスを確認できます。

サーバーは `0.0.0.0:8000` で待ち受け、アプリの3ファイルだけを配信します。Windowsファイアウォールの許可が必要な場合は、信頼できるプライベートネットワークに限って許可してください。終了はターミナルで Ctrl + C です。

## 通知音と制限

各区間の残り5〜1秒に短いビープ音を鳴らします。STARTをタップして音声を有効化してください。消音設定やブラウザによって音声は制限されます。

計時は実際の経過時間に基づきますが、バックグラウンドや画面ロック中の更新・音声は保証できません。取り逃した音はまとめて再生しません。画面を開いた状態で利用してください。

## ファイル構成

- `index.html`：設定・タイマー画面
- `style.css`：スマートフォン向けのダークUI
- `app.js`：設定検証、区間生成、計時、操作、通知音
- `dev-server.cjs`：LAN内テスト用HTTPサーバー
- `tests/app.test.cjs`：疑似DOM・時計・音声によるロジックの自動テスト

## テスト

```sh
node --test tests/app.test.cjs
```

実際の画面表示・音声・iPhone操作はブラウザで確認してください。
